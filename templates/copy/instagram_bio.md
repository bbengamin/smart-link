# Instagram Bio Template for Nearspoke

## Platform Notes
- Character limit: ~150 chars for bio, +23k story link caption space
- Nearspoke as primary or secondary URL (Instagram allows 3-5 links)
- Use `/api/og/[slug]` endpoint to generate shareable images when stories are shared

## Template Structure

```
[Value prop: 1 line max]
smartlink.app/business/{slug}

OR

☕ [Business type] in [location]. Book now. 👇
smartlink.app/business/the-coffee-roasters
```

## Ready-to-Use Variants

### Barbershop Example (150 chars)
```
Sharp cuts, fresh fades. Walk-ins welcome.
smartlink.app/business/sharp-cuts-barber
```

### Salon Example (148 chars)
```
Your hair, our craft. Book your style session.
smartlink.app/business/luxe-salon-bbq
```

### Dentist Example (135 chars)
```
Smile makeovers & cleanings. Same-day appointments.
smartlink.app/business/the-dentist
```

## With Story Link Copy (23k char limit)

```
We've got the latest on our newest collab. Check it out! [link]

→ New booking discount ends tonight ⏰ #booknow
```

OR

```
Fresh looks drop Friday 🎨 Save your spot: [link]
#hairgoals #newcollection
```

## Guidelines
- Keep under 150 characters for bio
- Include clear CTA (book now, check us out)
- Add relevant emoji (1-2 max)
- Use platform-specific hashtags sparingly
