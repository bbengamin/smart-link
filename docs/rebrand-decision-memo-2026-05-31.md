## Why Nearspoke Wins

1. **Clear meaning + brandable** — literally "close to voice/communication," naturally fits a SaaS orchestrator; short, pronounceable, no awkward consonant clusters.
2. **Zero public collisions** — exact GitHub repo search returns 0 repositories; clean namespace for software branding.
3. **No apparent domain registration** — RDAP queries return null on both `.app` and `.com`, suggesting it's available or held by a squatter unlikely to hold out (weak defensive signal anyway).
4. **Domainable** — `nearspoke.com` + `nearspoke.app` work as primary brand + platform identity; easy URL structure for docs, blog, support subdomains.

## Buying Order (Do This First)

Execute in this exact sequence to avoid wasting money:

### 1. Check live WHOIS / RDAP again
- Re-confirm availability with multiple registrars (Namecheap, Cloudflare, Porkbun).
- Capture screenshots of RDAP/WHOIS responses for legal disclosure if needed.

### 2. Purchase core domains (Priority: highest)
- `nearspoke.app` — primary SaaS landing; cheapest, clean brand signal.
- `nearspoke.com` — essential for SEO/backlink credibility; don't skip.
- Optional defensive TLDs if on budget: `nearspoke.io`, `nearspoke.co`.

**Registrar checkout order:** Start with Cloudflare (free WHOIS privacy, fast DNS) or Porkbun (cheap, clean). Complete `.app` first to lock it down before spending more.

### 3. Lock social handles
Check and buy on Twitter/X, GitHub, LinkedIn, Instagram: `@Nearspoke`. Secure these within 24 hours of purchase.

### 4. Legal/trademark clearance (before full rollout)
Before going public:
- Run USPTO TESS search for "NEAR SPOKE" / "NEARSPOKE" (phonetic + exact).
- Check EUIPO, UKIPO for EU/UK footprint if you plan to operate there.
- File trademark application before rebrand announcement if budget allows (~$250–$300 USD per class).

### 5. Redirects and SEO migration
Once legal clears:
- Set up `smartlink.app` / `smartlink.com` → `nearspoke.app` permanent redirects.
- Update internal links, DNS CNAMEs, favicon/cache before launch day.
