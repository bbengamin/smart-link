# Smart Link — Minimal Pilot Setup Checklist

Date: 2026-05-30
Scope: tiny, usable onboarding checklist for the first barbershop/salon pilot. No giant rollout theater.

## 1) Collect the minimum business info and assets
Required before launch:
- Business name exactly as it should appear publicly
- Owner or manager name
- Customer-facing phone number
- Owner/admin email address
- Address or neighborhood
- Opening hours
- Service list
- Starting prices
- Booking destination URL or booking preference if a live URL is not ready yet
- One approval contact who can say "launch it"

Helpful but not blockers:
- Instagram handle
- Google Business Profile URL
- Logo
- Brand colors
- 3-5 photos
- One-sentence shop description

## 2) Confirm the page essentials
Before the link goes live, make sure the pilot page shows:
- business name
- services
- starting prices
- hours
- location context
- customer contact buttons
- one primary booking button

If a customer cannot answer "what is this place, what can I book, how much, when are they open, and how do I contact them?" in 10 seconds, the page still sucks.

## 3) Set the contact buttons
Turn on only the buttons the owner will actually answer fast:
- Call button -> main phone line
- WhatsApp/SMS button -> active customer support number
- Map/directions button -> correct location
- Instagram button -> only if the account is active and monitored

Dead buttons are worse than missing buttons. They scream "we don't have our shit together."

## 4) Set the booking link
Use one primary booking CTA everywhere.
- If there is a live booking URL, use it.
- If there is no live booking URL yet, point the primary CTA to the best temporary contact path and say so clearly.
- Reuse the same destination across all launch surfaces so tracking and owner training stay simple.

## 5) Set owner alert expectations
Agree on this before launch:
- Owner should expect to see new demand in the dashboard/list.
- Instant alerts are optional, not magic. If Telegram/SMS/email alerts are configured, define who receives them.
- If instant alerts are not configured yet, the owner should still check the dashboard/list during pilot week.
- Someone specific must own follow-up for missed calls, messages, and booking requests.

## 6) Place the link on the first surfaces only
Launch in this order:
1. Google Business Profile website or appointment link
2. Instagram bio
3. Counter/front-desk QR code
4. WhatsApp/SMS saved reply

Do not spray it across every channel on day one. Start where intent already exists.

## 7) Give staff one saved reply
Use one blunt template:

"Here you go — this link has our services, prices, hours, and booking options: [smart link]. If you want help choosing a service, reply here."

## 8) Final launch check
Before calling setup done, verify:
- owner approved name, services, prices, hours, and main CTA
- booking button opens the right destination
- contact buttons point to real monitored channels
- at least the first 3 surfaces are live or queued today
- owner knows where new leads/bookings will appear
